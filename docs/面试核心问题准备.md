# 面试核心问题准备（世界模型方向）

> 用途：面试前快速梳理。每题按「一句话结论 → 展开逻辑 → 项目实证 → 诚实边界」组织，
> 所有数字均来自本仓库真实实验，可现场打开 `demos/` 图表佐证。

---

## Q1：世界模型解决了什么问题？

**一句话结论**：把昂贵的真实环境交互变成廉价的"脑内推演"——让智能体不碰环境就能
预测"执行这串动作后世界会变成什么样"。

**展开逻辑（三层递进）**：
1. **样本效率痛点**：机器人/强化学习靠真实试错，采样贵、慢、有损耗。世界模型在模型内
   rollout，一次真实交互的数据可以被反复"想象"利用。
2. **它具体输出什么**：给定当前观测 + 动作序列 → 预测未来每一步的**图像**（视觉想象）、
   **奖励**（这个动作好不好）、**价值**（长远回报多少）。三样齐了就能在想象里做规划
   和策略训练（Dreamer 的核心思路）。
3. **和普通视频预测模型的区别**：不是"猜下一帧好看"，而是**动作可控**的条件预测——
   同一起点、不同动作序列会得到不同未来，所以必须把动作显式注入动力学。

**项目实证**：
- 实现了开环想象：仅首帧 + 动作序列，20 步 rollout 全程不看真实帧，
  PSNR 27.7→21.8 dB，机械臂与立方体始终可辨（`demos/prediction/real_vs_pred20_traj0002.gif`）。
- 验证了想象训练链路：在想象轨迹上用奖励头反传梯度更新策略，回报 1.32→2.59 单调上升
  （`trainer/imagine_policy.py`）。
- 奖励预测 MAE < 0.007（归一化尺度），可作为想象中策略评估的信号。

**诚实边界**：全量训练未做轨迹级 held-out，指标反映保真度而非严格泛化；想象策略 Demo
存在 model exploitation（想象回报上升 ≠ 真实性能上升），下一步需要 λ-return + 价值引导
+ 定期回真实环境评估。

## Q2：RSSM 相比普通 RNN 好在哪里？

**一句话结论**：普通 RNN 是完全确定的"单一未来"，RSSM 把隐状态拆成
**确定态（记忆）+ 随机态（不确定性）**，既能记住历史，又承认"未来本来就不止一种"。

**展开逻辑**：
1. **确定性 RNN 的两个缺陷**：
   - 训练时只学"平均未来"——多模态未来（同一动作可能出现两种结果）会被 MSE 平均成
     一团糊；
   - 想象 rollout 时没有随机源，无法表达环境噪声与部分可观测性，误差单调累积且
     无法采样多条可能轨迹。
2. **RSSM 的结构**（DreamerV1/V2 均基于此）：
   - `h_t = GRU([z_{t-1}, a_t], h_{t-1})`：确定性态承载时序记忆（连贯性）；
   - `z_t ~ q(z|h_t,e_t)`（后验，训练用，看真实帧）与 `z_t ~ p(z|h_t)`（先验，想象用，
     纯动力学）：随机态承载不确定性（多模态表达）；
   - KL(q‖p) 把后验的动力学知识"蒸馏"进先验——**先验被约束得越贴后验，开环想象越准**。
3. **为什么这个设计天然适配策略学习**：随机态让模型能"采样多种未来"，配合 actor-critic
   就是在分布上估计回报（对不确定环境更稳健），这是纯确定性 RNN 给不了的。

**项目实证（本仓库最有说服力的一条）**：
- **KL 消融**：去掉 KL 后，训练 loss 看似更低（KL 项不参与），但真实 KL 飙到 18 nats
  ——后验与先验彻底脱节，开环想象从第 1 步就崩（PSNR 27.69→13.60，SSIM 0.92→0.15，
  奖励误差 ×12）。证明 KL 不是辅助正则，而是先验获得动力学能力的唯一通道。
- **free bits 消融（防 KL 坍缩）**：free_bits=1.0 时真实 KL 0.92 全被 clamp、梯度为零，
  先验预测糊（23.38 dB）；降到 0.2/0.05 后 KL 真正回传梯度，+5.7 dB。
  说明"KL 坍缩"是该框架的头号坑，free bits 是标准解法。
- **随机态维度消融**：stoch 16/32/64 对照，32 全程精度最优（step10 +1.75dB）、16 长程
  衰减最小——随机态容量存在最优点，不是越大越好（此前 128 实验同样劣于 64）。

## Q3：你的世界模型有什么创新 / 优化点？

**一句话结论**：轻量化 DreamerV2 核心复现 + 三个有数据支撑的原创优化/诊断，
全部结论可复现、有消融背书。

**三个主要点（按含金量排序）**：

1. **诊断并修复了"先验预测糊"的根因——不是 decoder 不行，而是 KL 被免费 bits clamp**。
   现象：后验重建 33 dB 清晰，先验预测却只有 23.4 dB 糊成一团。常规思路会去调 decoder
   或加数据；我通过 `trainer/diag_kl.py` 量化真实 KL 分布，发现 KL≈0.92 < free_bits=1.0
   被全部 clamp，**KL 梯度为零、先验从未被训练**。降 free bits 到 0.05 + kl_scale=1.5
   后单步 +5.7 dB、10 步开环 +2.3 dB。这个"先量化诊断再动手"的过程比调参本身更能
   说明对模型的理解。
2. **系统消融给出可信的容量配置**：随机态维度 16/32/64 对照 + 有/无 KL 对照，
   统一评估口径（同轨迹集/起点/种子），发现 stoch32 全程最优、stoch64 的 step10 存在
   明显低谷、无 KL 全面崩塌。结论直接落到默认配置建议（64→32）。
3. **工程闭环完整**：一键推理（动作序列→预测视频，三种动作来源）、配置单一权威来源
   （分辨率/序列长度/隐维度可配，VAE 自适应池化改造向后兼容旧权重）、GPU 显存预加载
   （训练 80× 加速）、统一评估脚本（三种口径严格区分），全流程一条命令可复现。

**范围与诚实的边界（主动说，比被问出来好）**：
- 聚焦算法层，基于 MuJoCo 离线轨迹验证，不涉及实机控制与部署；
- 轻量化复现：连续高斯隐状态（非 DreamerV2 的 categorical 离散态）、无 λ-return 与
  actor-critic 闭环（想象策略仅为最小 Demo）、全量训练无 held-out；
- 奖励尖峰低估、专家末段价值外推偏低等已知局限都有量化记录（README「已知限制」）。

**可能的追问与接法**：
- "为什么不用 categorical 隐变量？"——连续高斯实现简单、与本项目数据规模匹配；
  DreamerV2 论文显示 categorical 在 Atari 大规模任务上更稳，是我下一步的对照实验。
- "想象误差随步长累积怎么办？"——本仓库实测 1→20 步衰减 5.94dB、20 步处饱和回升，
  建议想象 horizon 10~16 步；缓解手段：更贴后验的先验（free bits 已证）、latent
  overshooting（训练时多步想象损失）、或 rollout 中周期性 re-observe。
