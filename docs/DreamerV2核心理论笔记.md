# DreamerV2 核心理论笔记

> 本笔记服务于 `vla-world-model-lab` 世界模型阶段，只抓核心数据流，不展开训练 trick。
> 参考：Hafner et al., *Mastering Atari with Discrete World Models* (DreamerV2, 2021)。

## 一、世界模型的三段式架构

```
观测图像 o_t ──> [视觉编码器] ──> 隐观测 x_t ──┐
                                              ├──> [RSSM 动力学] ──> 隐状态 h_t / z_t ──> [奖励头] ──> r̂_t
动作 a_t ─────────────────────────────────────┘                            │
                                                                          └──> [视觉解码器] ──> ô_t
```

1. **视觉编码器（Encoder）**：CNN 把 64×64 RGB 图像压缩成低维隐观测 `x_t`（如 64 维）。本仓采用轻量 CNN（4 层卷积 + MLP 头），与后续 VLA 视觉编码器接口预留一致。
2. **RSSM（Recurrent State Space Model）**：世界模型的「记忆与想象」核心。
   - 确定性状态 `h_t`：GRU 循环隐状态，携带历史信息，保证时序连贯。
   - 随机隐状态 `z_t`：离散分类变量（DreamerV2 用 32 类×32 维，straight-through 梯度），表达环境的随机性与观测噪声。
   - 先验 `p(z_t|h_t)` 在「想象」中采样；后验 `q(z_t|h_t,x_t)` 在「观察真实图像」时推断。训练时两者对齐。
3. **视觉解码器（Decoder）**：从 `h_t,z_t` 重建 `ô_t`，提供无标签的自监督信号。
4. **奖励头（Reward Head）**：从 `h_t,z_t` 预测 `r̂_t`，让隐状态携带任务相关信息。

## 二、训练目标（三损失）

| 损失 | 公式要点 | 作用 |
|---|---|---|
| 图像重建 | `-log p(o_t|h_t,z_t)`（伯努利或高斯） | 自监督 driving force，逼迫隐状态保留视觉信息 |
| KL 散度 | `KL(q(z_t|h_t,x_t) || p(z_t|h_t))`，用 free bits（最低 1 nat）防止塌缩 | 让先验可独立采样，支撑无观测的「想象 rollout」 |
| 奖励预测 | `-log p(r_t|h_t,z_t)`（离散回归或 MSE） | 让隐状态编码任务奖励结构 |

总损失 `L = L_img + β·L_KL + L_reward`（DreamerV2 常用 β=0.1 或 1.0，配合 free bits）。
注意：DreamerV3 后加入的「动力学方差 / 回报预测」等 trick 本阶段暂不引入。

## 三、RSSM 的设计意义（一句话版）

> 确定性循环状态保证「记住过去」，随机隐状态保证「承认世界不确定」——两者结合才能在隐空间里做多步想象rollout，而这正是后续 MPC / actor-critic 训练的数据来源。

## 四、本阶段落地路径（循序渐进）

1. **当前阶段**：图像 → 编码器 → RSSM → 解码器 + 奖励头，用 20 步序列做**单步重建与预测**验证（本目录数据集已就绪）。
2. 下一步：多步想象 rollout + KL 平衡调优；
3. 再下一步：在想象轨迹上训练 actor-critic（Dreamer 完整闭环）；
4. 远期：与 VLA 策略对接，用世界模型提供想象数据 augmentation。

## 五、关键术语速查

- **先验 / 后验**：先验只看 h（想象时用），后验额外看当前真实图像 x（训练时用）。
- **free bits**：KL 低于阈值（如 1 nat）时不回传梯度，防止 posterior 塌缩成先验导致隐状态无信息。
- **straight-through**：离散采样的梯度近似技巧，让分类隐变量可反向传播。
- **replay buffer**：世界模型训练用离线序列数据（本仓 HDF5 轨迹），与在线交互解耦。
