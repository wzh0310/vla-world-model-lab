# 数据集质量优化与增强（v1.0）

本文档记录对 VLA 数据集的质量抽查、数据增强与统计报告流程，产出 **v1.0 数据集**。所有脚本位于 `scripts/`，数据落在仓库外 `/data/wzh/robot/datasets/vla_pushcube_25/`（不入库）。

## 1. 质量抽查

`scripts/audit_vla_quality.py`（vla 环境，seed 20261126）：随机抽 3 条轨迹（本次为 ep1/ep5/ep21），逐帧核对图像-动作-指令匹配，检查四类问题：

- **指令错位**：每帧指令是否与 `template_id` 对应、类别是否一致 → 全局 0 错位；
- **动作异常值**：NaN/Inf、越界（[-1,1]）→ 全局均 0；
- **动作跳变**：初版按归一化空间相邻帧差 >0.9 判异常，3 条轨迹均被标 REVIEW（跳变 2.0）。排查发现是 **min-max 映射假象**：反归一化到物理空间后，最大跳变恰为 0.02m（专家控制律单步量程上限），`dy/dz` 跳变均小于各自量程，无任何超过 0.02m 的异常步。判定为 approach→push 阶段切换的正常结构，非损坏数据。判据已改为物理空间（≤ 单步量程 0.02m 为正常）。
- **图像模糊**：Laplacian 方差检测，抽查轨迹模糊帧 0，全局清晰度均值 783.77。

三条抽查轨迹最终全部 **PASS**（指令一致、帧索引连续、物理跳变在量程内、无模糊帧）。结果见 `quality_audit_v1.json`。

**经验**：归一化空间做阈值判断需谨慎——min-max 会把物理量放大到满量程，单步满速推进在归一化空间表现为 2.0 跳变，必须用物理量（米）复核异常值。

## 2. 数据增强（仅训练集）

`scripts/augment_vla_dataset.py`（vla 环境）：

### 图像增强
每条轨迹生成一个增强副本，随机参数**每条轨迹固定**（帧内一致，避免画面闪烁）：
- 亮度：乘性因子 U(0.85, 1.15)
- 对比度：U(0.85, 1.15)
- 高斯噪声：sigma U(0.0, 0.02)（像素 [0,1] 尺度）

实测原始 vs 增强帧平均绝对像素差 0.0647（生效且幅度轻微）。

### 指令增强
每个 `template_id` 预置 **2 条语义等价英文改写**（与原指令共 3 种表述），均指向「把立方体送到红色目标区」这一物理任务，不引入场景不存在的物体。对每条轨迹额外复制 2 份，分别用改写指令替换，图像/动作不变。20 条模板全部覆盖。

### 规模
源训练集 20 条轨迹 → 每条 4 个块（原始 + 图像增强 + 2 个指令改写）= **80 块 / 2980 帧**。验证集 **完全不变**（5 条 / 183 帧），作为微调效果对比基线。每份样本带 `aug_type` / `source_episode_id` 便于追踪。

注意：训练 20 条轨迹按分层划分只覆盖 16 个模板（另 4 个在验证集），这是正确的数据事实，不是缺陷。

## 3. 统计报告

`scripts/generate_vla_stats_report.py` 生成 `results/vla_dataset/stats_report_v1.md` + `stats_report.json`，覆盖：

- 轨迹数 / 帧数 / 单轨迹帧数分布；
- 指令分布（按 episode 去重精确统计类别与模板，避免采样偏差）；
- 动作范围（各维 min/max/mean(|x|)）；
- 图像统计（像素范围、Laplacian 清晰度）；
- **验证集基线指标**：183 帧 / 5 回合，清晰度均值 789.26，动作范围见报告表，未增强；
- 质量抽查结论与增强配置。

## 4. 校验

`scripts/verify_vla_v1.py` **19/19 PASS**：字段完整、增强类型齐全、帧数 2980、源轨迹 20、模板覆盖 16、每轨迹 4 块、指令同义映射正确（mismatch=0）、图像增强生效且幅度轻微、指令增强图像不变、动作增强前后不变、动作/图像范围、验证集图像/动作/指令逐字节不变、报告文件存在。

**性能坑**：v1.0 训练集 npz 约 439MB，`np.load` 解压与多次布尔索引较慢；验证脚本已全面向量化（np.unique/np.searchsorted 替代逐块循环）。本地 SSH 空闲超时会 SIGTERM 前台命令，大文件操作一律后台 `nohup` 运行并轮询日志；超时中断可能残留 99% CPU 子进程，需用 PID 精确清理（避免 `pkill -f` 匹配到自身命令）。

## 6. 与后续环节的衔接

- v1.0 训练集可直接做 LoRA 微调；图像增强提升对不同亮度/对比度环境的鲁棒性，指令同义增强提升语言泛化。
- 验证集保持原始，用于对比微调前后成功率与动作误差，衡量增强是否真正带来泛化收益。
- 若接入 OpenVLA 微调，需把 4 维动作扩 7 维（旋转补 0、夹爪二值化）并复用 `norm_stats.json`，勿混用 `unnorm_key` 的 q01/q99 统计量。
