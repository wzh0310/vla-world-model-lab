# 训练数据集扩充与全量调参报告

> 范围：算法层世界模型的数据侧与训练侧打磨，基于 MuJoCo PushCube 离线轨迹，
> 不涉及真实机器人底层控制。运行环境统一为 wzh-ai 容器（采集用 mujoco 环境、
> 格式化与训练用 vla 环境）。

## 一、数据生成（阶段一：数据生成）

### 1.1 目标与策略
补充多样化交互数据，提升世界模型泛化性。采用「随机策略 + 已训练 PPO 策略」混合采集：

| 策略来源 | 轨迹数 | 作用 |
|---|---|---|
| 已训练 PPO（`ppo_state_100000_steps.zip`）| 50 | 任务相关轨迹，覆盖接近目标的合理状态转移 |
| 随机策略（带 +x 弱偏置、幅度缩放）| 50 | 覆盖状态空间，提升对偏离分布帧的鲁棒性 |

PPO 为 state 输入的 SB3 策略，采集时以 `obs_mode=both` 同时取 13 维 state 喂策略、
224×224 RGB 帧作观测。已验证策略输出落在动作空间 `[dx,dy,dz,gripper]` 内。

### 1.2 多样性设计
- **立方体初始位置**：`randomize_start=True`，`start_xy_range=0.12`（原训练用 0.03），
  初始分布覆盖范围扩大 4 倍。
- **动作幅度**：每条随机轨迹采样幅度系数 `amp ∈ [0.4, 1.0]`；PPO 轨迹叠加小噪声
  `noise ∈ [0, 0.15]`，避免轨迹同质化。
- **来源打乱**：50+50 计划经随机排列后采集，避免数据按来源聚集。

### 1.3 规模（实测）
- 混合采集 **100 条 / 5000 帧**（平均 50 帧/条），来源 PPO 50 + 随机 50。
- 立方体初始位置跨度：x=0.230m、y=0.233m（原训练范围 0.06m，扩大近 4 倍）。
- 动作峰值幅度：均值 0.0187m，范围 [0.0107, 0.0200]m，覆盖不同动作幅度。
- 合并既有 100 条专家/随机轨迹后共 **200 条 / 8324 帧**；9:1 划分 train 180 条（7519 帧）
  / test 20 条（805 帧），校验 train/test 重叠轨迹 = 0，无数据泄漏。

## 二、数据格式化与增强（阶段二：格式化与增强）

### 2.1 标准轨迹格式
每条轨迹组统一为标准转移元组 `(observation, action, reward, next_observation, done)`：

| 字段 | 形状 | 说明 |
|---|---|---|
| `observations` / `images` | (T,224,224,3) uint8 | 观测帧 x_t（images 为兼容旧采样器保留同值副本）|
| `next_observations` | (T,224,224,3) uint8 | 下一帧 x_{t+1}，末帧自复制 |
| `actions` | (T,4) float32 | 动作 [dx,dy,dz,gripper] |
| `rewards` | (T,) float32 | 奖励 |
| `dones` | (T,) bool | 终止标记 |
| `states` | (T,13) float32 | 低维状态（奖励口径核对）|

### 2.2 划分
按轨迹粒度随机打乱后 **9:1** 划分 `train.h5` / `test.h5`，校验无重叠轨迹（无数据泄漏）。
混合采集数据与既有专家/随机轨迹合并，扩充训练规模。

### 2.3 轻量图像增强
在 GPU 显存采样器 `fast_loader.py` 中实现，遵循「整段序列共享增强参数」原则，
避免逐帧扰动破坏 RSSM 依赖的时序连贯性：

- **随机平移** ±2 像素
- **随机亮度/对比度** ±0.1
- **随机裁剪** ≤8%（通过随机缩放 + 中心裁剪实现，保留立方体绝对位置信息）

增强仅在训练 `sample()` 施加，评估用原始帧，保证指标可比。

## 三、全量训练与调参（阶段三：训练与调参）

### 3.1 调参方向落地

| 调参项 | 配置 | 依据 |
|---|---|---|
| 隐状态维度 | stoch_dim=48（32~64 区间）| 消融显示 32 精度最优、16 长程最稳，48 折中 |
| 学习率 | enc 1e-4 / dyn 3e-4（分组）| 编解码器求稳、动力学求快 |
| 序列长度 | 10 → 20 课程（1000 步线性增长）| 循序渐进，先易后难 |
| KL 权重 | 1.5（free_bits=0.05）| 已验证多步预测最优，防坍缩 |

### 3.2 训练监控
- TensorBoard 跟踪 **重建损失 / KL 散度 / 奖励预测误差** 三条核心曲线（另含价值损失）；
- 每 1000 步在测试集跑开环 20 步评估，按 SSIM 保存最优权重 `wm_best.pt`；
- 学习率余弦退火 + warmup 100 步。

### 3.3 达标目标与结果（实测）

训练 5000 步耗时 488 秒（约 8 分钟）。周期性开环评估（每 1000 步）显示 SSIM 稳步提升：

| step | 1000 | 2000 | 3000 | 4000 | 5000（最优）|
|---|---|---|---|---|---|
| 20步 SSIM | 0.5596 | 0.6678 | 0.7055 | 0.7113 | **0.7245** |
| 20步 PSNR(dB) | 19.62 | 21.04 | 21.77 | 21.77 | **21.98** |
| 奖励 MAE(归一化) | 0.0248 | 0.0167 | 0.0130 | 0.0128 | **0.0131** |

在完整测试集 15 条轨迹上用最优权重独立验证（`scripts/verify_targets.py`）：

| 指标 | 目标 | 实测 | 结论 |
|---|---|---|---|
| 20 步预测 SSIM | ≥ 0.6 | **0.7511** | PASS ✅ |
| 20 步预测 PSNR | — | 22.95 dB | — |
| 奖励预测 MAE（原始尺度）| < 0.5 | **0.0242** | PASS ✅ |
| 奖励预测 MAE（归一化）| — | 0.00242 | — |

重建损失从初始 0.33 收敛到 0.0093；KL 稳定在 0.05（free bits 生效，无坍缩）。
两项达标目标均大幅超出要求，扩充数据 + 分组学习率 + 课程训练方案有效。
