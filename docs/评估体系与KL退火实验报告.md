# 世界模型评估体系与 KL 退火实验报告

## 一、目标与背景

第 9-10 周的评估（`eval_single_step` / `eval_multistep_full`）以 PSNR/SSIM/奖励误差为主，
肉眼验证为辅。本周把评估升级为**客观、可复现的量化指标体系**，为调参提供统一标准；
同时按 Dreamer 标准核对动力学模型实现，并补上 **KL 权重退火**训练技巧，量化其对
训练初期收敛稳定性的影响。

## 二、评估指标体系（Day 2）

### 2.1 四级指标定义（`trainer/metrics.py`）

| 层级 | 指标 | 定义 | 衡量什么 |
|---|---|---|---|
| 像素级 | MSE / PSNR | 逐像素均方误差（[-1,1] 口径，峰值=2） | 像素精度 |
| 结构级 | SSIM | 滑窗结构相似性（channel_axis=2, data_range=2） | 视觉结构一致性 |
| 感知级 | 感知距离 | ResNet18（ImageNet）特征余弦距离，有界 [0,2] | 人眼感知相似度 |
| 动力学级 | 隐状态每步漂移 | 开环特征 vs teacher-forcing 后验特征的归一化 L2（‖Δf‖/√F） | 动力学模型漂移 |
| 任务级 | 奖励预测 MAE | 奖励头输出 vs 真实奖励（归一化尺度） | 下游策略可用性 |

> 感知级说明：LPIPS 原版（alexnet/vgg 权重）因外网受限（HTTP 403）不可下载，用容器内
> 已缓存的 ResNet18 ImageNet 权重实现同层级的**深度特征余弦距离**替代，接口与 LPIPS
> 对齐（`PerceptualMetric.distance(pred, target)`），联网后可无缝切换。像素/结构/感知
> 三层覆盖了"像素准 → 结构对 → 看起来像"的递进关系；隐状态漂移则把评估从像素空间
> 深入到动力学本身——像素误差可以因"预测偏了一点点"而暴增，而漂移直接度量 RSSM
> 隐状态偏离真实观测轨迹的程度。

### 2.2 统一评估入口（`scripts/eval_world_model.py`）

输入检查点 + 测试轨迹列表，自动完成：首帧后验起点 → 真实动作开环想象 N 步 →
teacher-forcing 平行分支逐帧 observe → 全部指标逐 step 计算 → 输出
`eval_curves.png`（精度-步长衰减曲线，4 子图）、`eval_metrics.json`、`eval_metrics.csv`。

口径：5 条专家轨迹 × 2 起点 × 20 步（与消融实验一致，可直接对比），seed=1234。

### 2.3 基线世界模型量化得分（wm_tune1，stoch64 + KL）

| 指标 | step1 | step10 | step20 | 变化趋势 |
|---|---|---|---|---|
| PSNR (dB) | 27.51 | 21.68 | 21.95 | 先衰减后饱和回升 |
| SSIM | 0.923 | 0.858 | 0.841 | 缓慢下降 |
| 感知距离 | 0.020 | 0.045 | 0.057 | 持续上升 |
| 隐状态漂移 (L2/√F) | 0.173 | 0.216 | 0.171 | 中段峰值后回落 |
| 奖励 MAE (norm) | 0.0026 | 0.0054 | 0.0093 | 缓慢上升 |

关键读数：
1. **PSNR 衰减 5.56 dB（1→20）**，与消融基线口径一致（5.94 dB，差异来自采样随机性）；
   衰减在 step9-10 后饱和回升，与第 10 周结论一致（建议想象 horizon 10~16 步）。
2. **隐状态漂移呈"先升后降"**：中段（step9）达峰值 0.22 后回落到 0.17——开环 rollout
   的隐状态并未单调发散，而是漂移后逐渐回到 RSSM 吸引子附近，与像素级饱和回升吻合。
3. **感知距离单调上升**（0.020→0.057）而 PSNR 饱和：像素误差稳定不代表感知质量稳定，
   感知级指标对"结构细节失真"更敏感，验证了多层级评估的必要性。
4. 奖励 MAE 全程 < 0.01（归一化尺度），满足想象策略训练的信号精度要求。

## 三、RSSM 动力学模型核对与 KL 退火（Day 3）

### 3.1 与 Dreamer 标准结构的逐项核对

本项目动力学模型**已按 Dreamer 标准 RSSM 实现**（`models/rssm.py`），逐项核对：

| 手册要求 | 项目实现 | 状态 |
|---|---|---|
| 确定性分支 GRU | `RSSM._transition`：GRUCell([z,a], h)，det_dim=200 | ✅ 已有 |
| 随机性分支高斯 | 对角高斯，stoch_dim=64，tanh 采样 + min_std | ✅ 已有 |
| 后验分布 | `observe()`：结合当前观测嵌入 q(z\|h,e)（训练用） | ✅ 已有 |
| 先验分布 | `imagine_step()`：仅历史隐状态+动作 p(z\|h)（想象用） | ✅ 已有 |
| 重建 + KL 损失 | 四损失：重建 + KL(free bits) + 奖励 + 价值 | ✅ 已有 |
| KL 权重系数防坍缩 | free bits 0.05（防 KL→0 坍缩）+ **本次新增 KL 退火** | ✅ 本次补齐 |

因此 Day 3 的增量是：**KL 权重退火**（手册建议"初始 0.1，逐步提升"）——此前项目用
恒定 kl_scale=1.5 + free bits，退火缺失。

### 3.2 KL 退火实现（`train_world_model.py --kl-warmup`）

- 新增 `kl_scale_at_step(step, target, warmup)`：前 warmup 步 KL 权重从 0.1 线性升至
  目标值（默认 1000 步升至 1.5），之后恒定。
- 设计动机：训练初期后验尚未成形，全量 KL 权重的大梯度可能把隐状态推向"后验≈先验
  但都学不到东西"的坍缩态；退火让重建先"立起来"，再逐步引入 KL 约束。
- TensorBoard 新增 `train/kl_scale` 曲线，日志行输出当前 ks 值。

### 3.3 对照实验结果

### 3.3.1 训练初期 KL 稳定性（TensorBoard loss/kl，前 2000 步）

| 统计量 | 基线（恒定 ks=1.5） | KL 退火（0.1→1.5，1000 步） |
|---|---|---|
| 早期 KL 均值 | 0.0508 | 0.0526 |
| 早期 KL 标准差 | 0.0003 | **0.0058** |
| 早期 KL 最大值 | 0.0517 | **0.0875** |
| 后期收敛值 | ≈0.050（贴 free bits 下限） | ≈0.050（同） |

曲线见 `outputs/kl_anneal_report/kl_anneal_compare.png`：退火组前 500 步 KL 明显更"活跃"
（峰值 0.087，超出 free bits 下限，说明有未被 clamp 的真实信息流），随后回落；约 750 步后
两条曲线汇聚到同一下限水平。两组均**未出现 KL→0 的后验坍缩**。

### 3.3.2 最终预测精度（统一评估口径，10 条开环 × 20 步）

| 指标 | 基线（恒定 ks） | KL 退火 | 变化 |
|---|---|---|---|
| PSNR@1 (dB) | 27.51 | **28.35** | **+0.84** |
| SSIM@1 | 0.923 | **0.932** | +0.009 |
| PSNR@20 (dB) | 21.95 | 21.26 | -0.69 |
| SSIM@20 | 0.841 | 0.831 | -0.010 |
| PSNR 衰减 (1→20) | 5.56 | 7.09 | +1.53 |
| 感知距离@20 | 0.057 | 0.060 | ≈持平 |
| 隐状态漂移@20 | 0.171 | 0.180 | ≈持平 |
| 奖励 MAE（均值） | 0.0028 | 0.0028 | 持平 |

### 3.3.3 结果解读（诚实记录）

1. **退火对单步精度有小幅收益**：step1 PSNR +0.84 dB、SSIM +0.009——训练初期小权重
   让重建先优化，起点状态的后验质量更好。
2. **退火对长程稳定性没有收益，衰减反而略增**（5.56→7.09 dB）：长程表现主要由先验-
   后验对齐质量决定，而本项目的对齐由 free bits 机制主导（两组后期 KL 曲线一致），
   退火在后期已无差异，单步收益无法转化为长程收益。
3. **两组都未发生 KL 坍缩**：手册预警的"训练初期 KL 直接到 0"在本项目配置下
   （free bits=0.05 + kl_scale=1.5）并未出现——**free bits 已承担防坍缩职责，退火属于
   冗余保险**。这解释了为什么收益有限。
4. **实践建议**：默认配置保持"free bits + 恒定权重"即可；若换更大数据集/更大模型
   （KL 坍缩风险更高的场景），可启用 `--kl-warmup` 作为保险项，其单步精度收益
   （step1 +0.84dB）也可保留。


## 四、结论

1. **评估体系从"肉眼 + 单一 PSNR"升级为四级量化指标**（像素/结构/感知/动力学），
   统一入口 `scripts/eval_world_model.py` 一条命令输出全部指标 + 精度-步长衰减曲线 +
   CSV/JSON，为后续一切调参提供客观标准。感知级指标的加入证实了其必要性：PSNR
   在 step9 后饱和，但感知距离仍在单调恶化（0.045→0.057）——像素误差稳定不代表
   结构细节没有持续失真。
2. **基线世界模型量化得分**（wm_tune1，10 条开环 × 20 步）：PSNR 27.51→21.95 dB
   （衰减 5.56，先衰减后饱和）、SSIM 0.923→0.841、感知距离 0.020→0.057、隐状态漂移
   峰值 0.22（step9）后回落、奖励 MAE 全程 <0.01。隐状态漂移"先升后降"表明 RSSM
   动力学存在吸引子效应，开环 rollout 不会单调发散。
3. **RSSM 结构核对确认已达标 Dreamer 标准**（GRU 确定性分支 + 高斯随机分支 +
   后验/先验双分布 + KL 对齐），本次增量补齐 **KL 权重退火**（--kl-warmup）。
4. **KL 退火对照实验（诚实结论）**：单步精度小幅收益（step1 +0.84 dB），长程无收益
   （衰减 5.56→7.09），两组均无 KL 坍缩——本项目的防坍缩由 free bits 主导，退火是
   冗余保险。实践建议保持默认配置，退火作为大规模场景的可选保险项保留。
5. **局限**：感知级指标用 ResNet18 特征余弦距离替代 LPIPS（外网权重 403），接口已
   对齐、联网可切换；退火实验为单次训练（未做多种子），结论以趋势为准。


## 五、复现方式

```bash
# 统一评估（基线）
python scripts/eval_world_model.py --ckpt outputs/wm_tune1/checkpoints/wm_step004000.pt \
    --trajs traj_0002,traj_0007,traj_0011,traj_0015,traj_0020 --starts 2,8 --steps 20
# KL 退火对照训练（4000 步，约 8 分钟）
python trainer/train_world_model.py --config configs/default.yaml \
    --kl-warmup 1000 --max-steps 4000 --output-dir outputs/wm_klanneal
# 退火模型统一评估 + KL 曲线对比
python scripts/eval_world_model.py --ckpt outputs/wm_klanneal/checkpoints/wm_step004000.pt \
    --out-dir outputs/eval_klanneal
python trainer/kl_anneal_report.py
```
