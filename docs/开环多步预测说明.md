# 开环多步预测说明

## 一、它解决什么问题

单步预测（teacher forcing）每一步都用真实前一帧刷新后验状态，本质上是 N 次独立的
"下一帧预测"，无法回答一个关键问题：**只给一张初始帧和一段动作序列，世界模型能否
自己在脑子里把未来推演出来？** 这正是"在世界模型内想象训练策略"的前提。

`imagine_rollout()` 就是这个能力的核心接口：从初始状态出发，只接收动作，
**全程不接入任何真实图像**，自回归展开任意 N 步。

## 二、两种预测口径对照

| 口径 | 每步是否看真实帧 | 性质 | 本次 PSNR |
|---|---|---|---|
| 开环预测 `imagine_rollout` | 否（仅 t=0 建初始状态） | 真·想象，误差会累积 | 前3步 27.43dB → 后3步 21.01dB |
| 单步预测 `imagine_step`（teacher forcing） | 是（每步刷新后验） | 上界参考 | 30.12dB |

开环后段比前段低约 6.4dB 是**预期现象**：没有真实帧纠错，隐状态的微小偏差会随步数
累积。这也正是后续要用价值头 / actor-critic 在想象轨迹上学习、以及需要长rollout
正则化的动机。

## 三、接口实现（`models/rssm.py`）

```python
# 1) 开环展开：只喂动作，不接真实图像
states, infos = rssm.imagine_rollout(initial_state, actions, sample=True)
#   initial_state : 由真实首帧编码后的后验状态（唯一一次用真实图像）
#   actions       : (B, N, 4) 或 (N, 4)（单样本自动广播）
#   states        : List[RSSMState]，长度 N，每步含 det / stoch

# 2) 批量解码：N 步特征一次性过 decoder -> 预测视频帧
frames = rssm.decode_rollout(states, decoder)   # (N, B, 3, 64, 64)
```

关键设计点：
- `imagine_rollout` 内部只调用 `imagine_step`（纯先验 GRU + 先验高斯），
  **不调用 `observe`、不读任何 embed**，保证真正的开环。
- 动作序列支持 `(B,N,A)` 与 `(N,A)` 两种形状，单样本在 batch>1 时自动广播。
- `imagine_step` 新增 `sample` 开关：`False` 时用先验均值 `tanh(mu)`，
  得到确定性预测，便于复现与调试。
- `decode_rollout` 把 N 步拼接特征一次性送入 decoder，避免逐步 Python 循环。

## 四、基础测试与产出

`trainer/test_open_loop.py` 完成端到端验证：

1. 取专家轨迹首帧编码为初始状态；
2. 输入后续 10 步动作，开环生成 10 步隐状态并解码为图像；
3. 健全性检查：状态长度、det=(1,200)/stoch=(1,64)、随机态 ∈[-1,1]、无 NaN；
4. 输出逐步 PSNR/SSIM 与误差累积摘要，生成对比视频。

运行：

```bash
$VLA trainer/test_open_loop.py --ckpt outputs/wm_fb02/checkpoints/wm_step004000.pt
# 可指定任意步长：--steps 20
```

产出（位于 `outputs/wm_fb02/`，不入 git）：
- `vis/open_loop_rollout.gif`：逐帧 [真实 | 开环预测] 动图
- `vis/open_loop_rollout.png`：3×10 静态对比（真实 / 开环 / 单步）
- `metrics/open_loop_eval.json`：逐步指标与误差累积摘要
