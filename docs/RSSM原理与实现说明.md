# RSSM 原理与实现说明

## 一、RSSM 要解决什么（原理补学要点）

世界模型要在**没有真实观测**的情况下预测未来（想象 rollout），但纯确定性 RNN 无法表达环境的随机性，纯随机模型又记不住历史。RSSM 的解法是两套状态并存：

- **确定性隐藏态 h_t**（GRU 输出）：递归携带历史信息，保证时序连贯 ——「记住过去」；
- **随机隐状态 z_t**（MLP 输出分布参数后采样）：表达环境随机性与观测噪声 ——「承认不确定」。

DreamerV2 的 z_t 是离散分类变量；本骨架为降低复杂度先用**对角高斯 + tanh**（64 维，与 AE 全量训练后的隐空间对齐），接口保持一致，后续可无缝替换。

## 二、前向逻辑（每一步 t）

```
                      上一状态 (h_{t-1}, z_{t-1}) + 动作 a_{t-1}
                                       │
                                  GRUCell  ──>  h_t            （确定性态）
                                       │
              ┌────────────────────────┴────────────────────────┐
              │ 后验（训练，有真实图像）                         │ 先验（推理，无图像）
              │ posterior([h_t, embed_t]) -> (mu_q, logvar_q)   │ prior(h_t) -> (mu_p, logvar_p)
              │ z_t = tanh(mu_q + eps*sigma_q)                  │ z_t = tanh(mu_p + eps*sigma_p)
              └────────────────────────┬────────────────────────┘
                                       │
                          get_feature = concat(h_t, z_t)  -> 解码器 / 奖励头
```

- 训练时同时算后验与先验，两者 KL 散度作为损失，逼迫先验学会「不看图像也能预测 z」；
- 推理/想象时只用先验（imagine_step），完全脱离真实图像。

## 三、三个核心方法（`models/rssm.py`）

| 方法 | 输入 | 输出 | 用途 |
|---|---|---|---|
| `observe(state, action, embed)` | 上一步状态、动作、当前图像嵌入 | 新状态 + 先验/后验分布参数 | 训练：基于真实序列推断后验收敛 |
| `imagine_step(state, action)` | 上一步状态、动作 | 新状态 + 先验分布参数 | 推理：无图像的想象 rollout |
| `get_feature(state)` | 状态 | 拼接特征 (B, 232) | 供给解码器和奖励头 |

辅助方法 `initial_state(B)` 返回零初始状态；采样用 `softplus(logvar)+min_std` 保证标准差正值，`tanh` 限制随机态范围。

## 四、维度设计（与 AE 对齐）

| 维度 | 取值 | 说明 |
|---|---|---|
| stoch_dim | 64 | 随机态，对齐 AE 全量训练后的 64 维隐空间 |
| det_dim | 200 | 确定性 GRU 隐藏态（Dreamer 常用尺寸） |
| action_dim | 4 | `[dx,dy,dz,gripper]` |
| 拼接特征 | 264 | 200 + 64，解码器/奖励头的输入 |
| embed_dim | 64（可延迟推断） | 图像编码器输出的嵌入维度 |

RSSM 参数量 294,992。

## 五、自检结果

- 单步：observe / imagine_step 输出 det=(B,200)、stoch=(B,32)，特征=(B,264) ✓
- 序列：20 步 observe rollout 稳定；5 步纯先验 imagine 正常 ✓
- 随机性：同输入两次采样结果不同（重参数化生效）；stoch 经 tanh 在 [-1,1] ✓
- KL：先验/后验分布参数可直接计算 KL 散度 ✓

## 八、与 AE 的维度对齐说明（重要）

AE 全量训练后隐空间为 **64 维**（`ConvVAE(latent_dim=64)`），因此 RSSM 的随机态
`stoch_dim=64` 与之对齐。注意两者的语义分工：

- AE 的 64 维隐变量 z 是「图像压缩表示」，由编码器直接从单帧图像推断；
- RSSM 的 64 维随机态 z_t 是「动力学隐状态」，由 GRU + 先验/后验网络在序列中演化。

二者维度相同，便于后续把 AE 编码器作为 RSSM 的观测嵌入来源（embed）、把 AE 解码器
接在 `get_feature()` 之后。由于 `get_feature()` 输出 264 维（det 200 + stoch 64），
整合时需要一个 264→64 的投影层再送入现有解码器，或直接训练一个接收 264 维特征的新
解码器——这是下一步单步预测训练要解决的接口问题。
