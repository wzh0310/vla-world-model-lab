# 想象策略训练最小 Demo 说明

## 一、目的与定位

本 Demo 验证世界模型的核心下游价值：能否**完全在世界模型内部**训练一个策略，而不消耗任何真实环境交互。

**明确定位：这是链路验证，不是策略性能验证。** 目标只有三条：
1. 「世界模型 → 想象轨迹 → 策略更新」链路能跑通；
2. 奖励信号能通过可微世界模型把梯度回传到策略参数；
3. 想象中的预测奖励总和随训练有上升趋势。

不追求学到的策略能在真实环境推好立方体——那需要更复杂的 λ-return、价值蒸馏、策略蒸馏与充分的奖励头校准。

## 二、实现

### 2.1 策略网络 `models/policy.py`

`MLPPolicy`：隐状态特征（264 维 = det 200 + stoch 64）→ 256 → 128 → 4 维动作，
隐藏层 SiLU，输出层 `tanh` 限制到 `[-1,1]`（与环境归一化动作空间一致）。参数量约 10 万。
与 DreamerV2 actor 同构（确定性均值策略），但不带高斯采样，随机性由世界模型随机态提供。

### 2.2 想象训练逻辑 `trainer/imagine_policy.py`

每轮迭代：
1. **起点**：从真实轨迹采样起点，用真实首帧 + `RSSM.observe` 建立后验状态（这是 Dreamer
   标准做法；想象本体不含真实帧，起点用真实帧编码是允许的）。默认每轮重采样起点；
   `--fixed-init` 固定同一批起点以消除起点方差、凸显策略学习信号。
2. **想象展开**：H=15 步全程在模型内——`policy(feature) → action → rssm.imagine_step`（只调
   先验，**不接任何真实图像**）`→ reward_head(feature) → r_t`。horizon=15 依据 Day11 评估
   结论（想象宜 10~16 步，避免模糊平衡态失真）。
3. **回报与更新**：`R = Σ γ^t r_t`（γ=0.99），`loss = -R.mean()`。世界模型参数全部冻结
   （`requires_grad=False`）但**保留在计算图中**——梯度经"奖励 → 隐状态 → 动作 → 策略参数"
   完整回传，只更新策略。这是本 Demo 验证的关键机制。
4. **可选 baseline**（`--baseline`）：加载价值头对每步特征的价值预测作 baseline，用优势
   `A = Σ γ^t (r_t - V_t)` 更新策略（Dreamer 的 critic 降方差做法），已验证可跑通。

复现命令（vla 环境）：
```bash
VLA=/opt/miniconda3/envs/vla/bin/python
# 主实验（固定起点，单调上升曲线）
$VLA trainer/imagine_policy.py --ckpt outputs/wm_tune1/checkpoints/wm_step004000.pt \
    --iters 300 --fixed-init --out-dir outputs/imagine_policy
# 可选：价值头 baseline 版
$VLA trainer/imagine_policy.py --iters 300 --fixed-init --baseline --out-dir outputs/imagine_policy_bl
```

## 三、结果

主实验（300 迭代，固定起点，确定性先验，batch=16，lr=1e-3）：

| 指标 | 数值 |
|---|---|
| 训练前想象回报（iter 1） | 1.32 |
| 训练后想象回报（iter 300） | **2.59** |
| 提升 | **+0.68（+52%）** |
| 梯度范数 | 1.15 → 0.0014（平滑收敛） |
| 趋势判定 | `rising=True`，单调上升后趋平 |

趋势图 `outputs/imagine_policy/vis/imagine_return_curve.png` 显示：回报从 1.32 单调上升，
约 iter 50 后收敛到 2.58 附近，梯度范数持续衰减——证明策略确实在利用世界模型的可微
动力学优化行为，链路完全打通。完整数据见 `metrics/imagine_policy.json`。

## 四、诚实说明与局限

1. **专家动作基线反常低**：探针显示随机策略回报 1.69、专家动作回报仅 0.48，训练后策略
   （2.59）反而最高。这不是 bug，而是 **model exploitation / 分布偏移** 的典型信号：
   奖励头在真实轨迹的**后验特征**上训练，而想象展开用的是**先验特征**（纯动力学，与后验
   有约 4 dB 差距），专家动作序列在想象中会把状态带偏离奖励头的高值区；策略优化则学会了
   利用奖励头的这种偏好。**这正说明"想象回报上升"不等于"真实环境性能上升"**，是必须
   记住的局限。
2. **起点方差**：每轮随机重采样起点时，不同起点的回报差异（1~5.5）会淹没学习信号，曲线
   剧烈震荡（rising 甚至判为 False）。因此主实验用 `--fixed-init`。真实 Dreamer 靠大 batch
   + 价值函数 + 长训练化解此问题，本 Demo 用固定起点做了简化。
3. **无 λ-return / 无策略蒸馏**：用简单折扣回报而非 Dreamer 的 λ-return + 价值函数引导，
   也未把世界模型特征蒸馏回 Actor 的输入。这是"最小可用"的取舍。
4. **世界模型本身未微调**：全程冻结，策略只能适应现有模型，无法反过来改善模型。

## 五、结论与下一步

链路验证达成：世界模型可以作为可微模拟器，通过想象轨迹把奖励梯度回传给策略，且想象回报
随训练单调上升。这证实了世界模型的下游价值，为完整 DreamerV2 闭环奠定了基础。

下一步（若继续）：引入 λ-return + 价值函数引导 + 策略蒸馏，并用真实环境定期评估，检验
"想象回报上升"能否转化为真实性能提升，同时缓解 model exploitation。
