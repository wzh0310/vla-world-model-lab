# 多步预测调优实验报告

## 一、问题与目标

多步开环预测（仅首帧 + 动作，全程不看真实图像）随步数增加会越来越模糊：误差逐步累积，
立方体逐渐被机械臂模糊伪影吞没。目标是让 10 步预测中立方体位置仍清晰可辨。

基线（`outputs/wm_heads` 4000 步，free_bits=0.2 / kl_scale=1.0 / stoch=64，无增强）：
整体 PSNR **22.39dB**，前3步 24.61 → 后3步 20.90dB，后3步 SSIM 0.829。

## 二、三个优化方向

按递进式设计三组实验，每组在上组基础上叠加一个优化，便于分辨各自贡献：

1. **KL 损失权重调整**（实验1）：free_bits 0.2→0.05、kl_scale 1.0→1.5。
   动机：此前实测真实 KL≈0.17 < free_bits 0.2，KL 被 clamp 致梯度为零；降到 0.05
   让 KL 真正回传梯度、先验更贴近后验，缓解开环误差累积。
2. **增大随机隐状态维度**（实验2）：stoch_dim 64→128（det 保持 200，特征 328 维）。
3. **图像增强**（实验3）：开启随机平移（±2px）+ 亮度扰动（±0.1），整段20帧共享参数。

## 三、实验结果（统一口径：5 条专家轨迹 × 3 起点 = 15 条开环 × 10 步）

| 配置 | 整体PSNR | 前3步 | 后3步 | 累积下降 | 后3步SSIM |
|---|---|---|---|---|---|
| 基线 | 22.39 | 24.61 | 20.90 | 3.71 | 0.829 |
| **实验1：KL调优** | **24.71** | 26.59 | **22.91** | 3.68 | **0.873** |
| 实验2：+stoch128 | 24.33 | **26.87** | 22.43 | 4.44 | 0.870 |
| 实验3：全开+增强 | 21.90 | 23.45 | 20.74 | 2.71 | 0.726 |

逐 step PSNR（实验1 vs 基线）：
- 基线：25.9 / 24.4 / 23.5 / 22.4 / 21.8 / 21.9 / 21.3 / 21.1 / 20.9 / 20.7
- 实验1：27.0 / 26.6 / 26.2 / 25.6 / 24.9 / 24.4 / 23.7 / 23.2 / 22.8 / 22.7
每一步都提升 1~2dB，且曲线更平缓。

## 四、结论与取舍（诚实记录）

- **KL 调优有效且是唯一净收益项**：整体 +2.32dB、后3步 +2.01dB、后3步 SSIM
  0.829→0.873。降低 free_bits 让先验学到更准的动力学，多步预测全面受益。
- **增大 stoch_dim 64→128 反而变差**：虽然前3步略高（26.87），但后3步降到 22.43、
  累积下降扩大到 4.44dB。随机态维度增大带来更多采样不确定性，开环时误差累积更快。
  **不采纳**。
- **图像增强明显有害**：整体掉到 21.90dB、后3步 SSIM 崩到 0.726。原因是平移/亮度扰动
  对"精确复现立方体位置"构成标签噪声——本任务是精确定位而非语义分类，增强会破坏
  立方体位置的精确监督。视觉上立方体被糊块吞没更严重。**不采纳**。
- 增强与增维虽然让"下降量"变小（2.71），但那是整体水平大幅下降后的假象（起点就低），
  不是更稳定。

**最终采纳：仅 KL 调优（实验1）**，检查点 `outputs/wm_tune1/checkpoints/wm_step004000.pt`，
已同步更新 `configs/default.yaml`（free_bits=0.05 / kl_scale=1.5）。

## 五、视觉验证：立方体可辨

聚焦中央区域放大对比（第10步，最难时刻，`vis/cube_focus_step10.png`）：
- **基线**：黄绿色立方体几乎被机械臂的白色模糊伪影吞没，位置难以分辨。
- **实验1（采纳）**：立方体是独立清晰的黄色小点，位置与真实帧大致对应；红色目标圆盘清晰。
机械臂末端仍有轻微模糊（VAE 类固有现象），但任务关注的关键物体——立方体位置——明确保留。

## 六、复现命令

```bash
VLA=/opt/miniconda3/envs/vla/bin/python
# 最优模型训练（配置已固化最优超参）
$VLA trainer/train_world_model.py --config configs/default.yaml --output-dir outputs/wm_tune1
# 统一多步评估
$VLA trainer/eval_multistep.py --ckpt outputs/wm_tune1/checkpoints/wm_step004000.pt --out-dir outputs/wm_tune1
# 立方体聚焦可视化
$VLA trainer/vis_cube_focus.py --ckpt outputs/wm_tune1/checkpoints/wm_step004000.pt --out outputs/wm_tune1/vis/cube_focus.gif
```

说明：输出目录 `outputs/` 不入 git（体积大），评估结果 JSON 存于各目录 `metrics/`。
图像增强代码已入库（`datasets/fast_loader.py` 的 `--augment` 开关，默认关闭），
作为可选能力保留，但本任务实测对定位任务有害，默认不启用。
