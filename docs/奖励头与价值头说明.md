# 奖励头与价值头说明

## 一、目标

在世界模型上补齐两个预测头，让训练损失从"重建 + KL + 奖励"三损失扩展为四损失，
为下一步在想象轨迹上训练 actor-critic 做准备：

- **RewardHead**：隐状态特征 → 单步奖励（回归），是原内联奖励头的模块化重构。
- **ValueHead**：隐状态特征 → 状态价值 V(s_t)，训练目标是该步起的折扣回报。

## 二、实现（`models/heads.py`）

```python
from models.heads import RewardHead, ValueHead
rh = RewardHead(feat_dim=264)   # 输入 det(200)+stoch(64)
vh = ValueHead(feat_dim=264)
# 各自定义：Linear(264,256) -> SiLU -> Linear(256,128) -> SiLU -> Linear(128,1)
```

关键设计：**两个头均继承 `nn.Sequential`**，所以权重 key 是 `reward_head.0.weight`
这类形式，与旧版训练脚本内联的 `nn.Sequential` 完全一致。好处：

- 历史检查点（`v0.1.x`）的 `reward_head.*` 可直接加载；
- 既有评估脚本 `eval_single_step.py` / `make_prediction_gif.py` 按前缀切片加载不受影响；
- `resume` 旧检查点时缺失的 `value_head.*` 随机初始化即可（训练脚本已用
  `strict=False` 兼容）。

## 三、训练接入（`trainer/train_world_model.py`）

价值目标采用"每步起的折扣回报"，与训练 20 步窗口口径一致：

```
G_t = r_t + γ·r_{t+1} + γ²·r_{t+2} + ...   (窗口内，γ=0.99)
loss = rec + kl_scale·kl + reward_scale·rew + value_scale·val
```

新增超参（已写入 `configs/default.yaml`）：`value_scale=1.0`、`gamma=0.99`。
四损失全部收敛（4000 步，vla/A6000 GPU，433 秒）：

| 损失 | 起步 | 收敛 | 说明 |
|---|---|---|---|
| 重建 rec | 0.320 | 0.0043 | 稳定 |
| 奖励 rew | 0.0048 | 0.00006 | 收敛良好 |
| 价值 val | 0.122 | 0.0007 | 收敛良好 |
| KL | 0.200 | 0.200 | clamp 后值；真实 KL 约 0.17（见前期诊断） |

## 四、奖励 / 价值曲线验证（`trainer/verify_heads.py`）

对专家轨迹用后验特征做单步预测（与训练口径一致），对比预测曲线与真实曲线：

| 轨迹 | 奖励 corr | 奖励 MAE | 价值 corr | 价值 MAE |
|---|---|---|---|---|
| traj_0002 | 0.792 | 0.0543 | 0.505 | 1.055 |
| traj_0007 | 0.746 | 0.0544 | 0.634 | 1.056 |

- **奖励曲线趋势一致**：相关系数 0.767，显著正相关；成功前的缓升趋势被捕捉到。

## 五、已知限制（诚实说明）

1. **奖励尖峰幅值低估**：真实奖励在成功帧有尖峰（接近 1.0），预测只到约 0.05。
   相关系数为正是因大量零值抬升，但尖峰幅度被平均。根因是奖励极稀疏（>0.5 的帧
   仅占 2.56%），MSE 回归倾向预测条件期望。方向性可用，幅值不可直接当回报估计。
2. **价值预测在专家轨迹末段偏低**：价值相关性 0.55、MAE 1.06。诊断发现随机 20 步
   窗口折扣回报均值仅 -0.0015、p90 为 0.088，绝大多数窗口价值目标近零，所以价值头
   学到的是"预测接近 0"——这是稀疏奖励下的正确条件期望。专家轨迹末段因累积高奖励
   目标升到 2.0，属于**分布外外推**，不是训练失败。
3. **价值头尚未用于训练信号**：当前只在真实轨迹 supervision 下学习，尚未接入
   λ-return / 想象 rollout 的优势计算。
