# 世界模型联合训练说明

## 一、训练目标与架构

在 AE 视觉通道基础上接入 RSSM 动力学，形成 DreamerV2 风格三段式世界模型：
**ConvEncoder（复用 AE 权重）→ RSSM（GRU 确定性态 200 + 对角高斯随机态 64）→ ConvDecoder + 奖励头**。

联合损失（三项目标，训练脚本 `trainer/train_world_model.py`）：

| 损失 | 公式 | 作用 |
|---|---|---|
| 重建损失 | MSE(decoder(feature), 真实 x_t) | 让隐状态编码足够多的视觉信息 |
| KL 散度 | KL(q后验 ‖ p先验)，含 free bits | 约束先验与后验一致，使纯动力学预测可用 |
| 奖励预测 | MSE(reward_head(feature), r_t) | 让隐状态携带奖励信息，供后续规划 |

**free bits 技巧**：对每行 KL 先 `clamp_min(free_bits)` 再取均值（默认 1.0 nats）。
训练初期先验还没学会匹配后验，若不加下限，KL 会被优化成 0 导致「先验坍缩」——
模型退化成只能靠真实图像推断、失去纯动力学想象能力。

## 二、数据流（单步监督，20 步序列）

对序列每一步 t：
1. 真实图像 x_t 经编码器得 embed_t（后验输入）
2. `rssm.observe(state_{t-1}, a_t, embed_t)` → 后验状态 s_t，同时返回 prior/post 分布参数
3. s_t 的拼接特征（264 = det200 + stoch64）→ 解码器重建 x_t、→ 奖励头预测 r_t
4. prior/post 参数算 KL（free bits）

每一步都用真实图像做后验（teacher forcing），是标准的单步监督训练；
`imagine_step`（纯先验想象）不参与本阶段损失，留待后续多步 rollout / 规划。

## 三、训练配置与结果

- 数据：100 条轨迹、20 步序列、batch 32、seed 0、A6000（GPU 内存预加载采样器）
- 优化：AdamW lr 3e-4（warmup 100 步 + 余弦衰减）、梯度裁剪 1.0、3000 步、约 326 秒
- 权重初始化：encoder 与 decoder 转置卷积从 AE 检查点迁移，decoder.project 因输入维度从 64→264 重新初始化

| 指标 | 起点 | 终点 |
|---|---|---|
| 重建 MSE | 0.316 | **0.00294** |
| 奖励 MSE | 0.00130 | **0.00005** |
| KL（free bits 后） | 1.000 | 1.000（全程被 clamp） |
| 梯度范数 | 0.75 | 0.004–0.13（无爆炸） |

**关于 KL 恒为 1.0 的诚实说明**：这说明真实 KL 一直低于 1.0 阈值、被 free bits clamp，
因此 KL 项几乎没有产生梯度——先验网络学习压力很小。重建损失下降主要来自后验路径与解码器。
这在本阶段（单步监督、目标是跑通）是可接受的，但意味着**先验预测能力还未被充分训练**。
后续改进方向：降低 free bits 阈值（如 0.1~0.3）让 KL 真正参与优化，或加入多步 imagine 时的
KL 监督（Dreamer 的 lambda-return / 多步预测损失）。

## 四、单步预测验证（`trainer/verify_world_model.py`）

加载 step3000 检查点，输入初始帧 + 动作序列：

| 预测方式 | MSE | PSNR | 说明 |
|---|---|---|---|
| 后验重建（上界） | 0.00207 | **32.87 dB** | 看到真实下一帧后重建，与 AE 水平一致 |
| 先验单步预测 | 0.03537 | **20.53 dB** | 纯动力学（只有初始帧+动作），保留场景结构 |

肉眼对比（`outputs/wm/vis/prediction.png`，4 排 × 8 列）：后验重建清晰可辨；
先验预测保留了红点位置与桌面轮廓，但有明显模糊与噪点——这是 VAE 类世界模型
纯动力学预测的典型现象，与上文「KL 未充分训练」的诊断一致。
已达成「单步预测可正常收敛、可运行」的目标；预测清晰度是后续优化项。

## 五、复现命令

```bash
# 联合训练（3000 步，约 5.5 分钟，不含约 90 秒预加载）
python trainer/train_world_model.py --max-steps 3000 --batch-size 32 \
  --log-interval 100 --vis-interval 1000 --save-interval 1000 --free-bits 1.0

# 单步预测验证
python trainer/verify_world_model.py --ckpt outputs/wm/checkpoints/wm_step003000.pt --num-samples 8
```

## 六、已知限制与下一步

1. KL 恒为阈值，先验训练不充分 → 调低 free bits 或加多步想象损失
2. 先验预测 20dB 偏模糊 → 更长的训练、增大 KL scale、或用离散隐变量（DreamerV2 的 categorical）
3. 尚未接入演员-评论家（actor-critic）与想象 rollout，世界模型目前只用于重建/预测验证
