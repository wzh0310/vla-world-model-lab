# 视觉自编码器实现说明

## 一、模块结构（`models/vae.py`）

| 类 | 作用 | 结构 |
|---|---|---|
| `ConvEncoder` | 64×64×3 图像 → 隐分布 (mu, logvar) | 4 层卷积 64→32→16→8→4，每层 Conv2d(stride=2) + GroupNorm(1) + SiLU，展平后 Linear → 2×32 |
| `ConvDecoder` | 32 维 z → 64×64×3 图像 | Linear 投影到 256×4×4，4 层 ConvTranspose2d(stride=2) 4→8→16→32→64，末层 Tanh 输出 [-1,1] |
| `ConvVAE` | 封装，支持重参数化采样 / 纯 AE 取 mu | 参数量 1,778,819 |

- 归一化用 `GroupNorm(num_groups=1)`（对所有通道归一化，卷积特征图上的层归一化标准实现，小 batch 稳定）。
- 本阶段为**纯自编码器**：前向默认取 mu（确定性），`sample=True` 时重参数化采样，为后续 RSSM 预留接口。

## 二、训练脚本（`trainer/train_ae.py`）

- **损失**：图像 MSE 重建损失（无 KL，纯 AE 阶段）。
- **学习率**：线性 warmup（200 步）+ 余弦衰减到 0；支持 AdamW + 权重衰减 + 梯度裁剪。
- **检查点**：每 `save_interval` 步保存到 `outputs/checkpoints/ae_step*.pt`，含模型/优化器/步数/参数，**可续训**（`--resume`）。
- **TensorBoard**：`train/mse`、`train/lr`、`eval/mse`、`重建对比` 图像，日志在 `outputs/logs/ae/`。
- **可视化**：每 `vis_interval`（默认 500）步保存「上排原图 / 下排重建」对比到 `outputs/ae_vis/recon_step*.png`。

## 全量训练验收与 GPU 加速（本轮更新）

### 训练瓶颈与解决
早期训练脚本用 `EpisodicDataset` + DataLoader 逐帧在 CPU 上 resize 20 张 224×224 图，
GPU 利用率仅约 1%，100 步耗时 400+ 秒。新增 `datasets/fast_loader.py::GPUSequenceSampler`：
启动时一次性把全部轨迹图像 resize 到 64×64 并常驻显存（100 条约 82MB），训练循环纯显存切片。
`trainer/train_ae.py` 默认走此路径（`--fast`，可用 `--no-fast` 回退）。

- 加速效果：**1000 步从约 70 分钟降到 51 秒**（含 17 秒预加载），约 80×。
- 完整功能保留：warmup + 余弦衰减、TensorBoard、每 500 步重建图、eval、检查点、续训。

### 全量训练结果（1000 步，latent=64，batch=64，seed=0，A6000）
| 指标 | 起点 | 终点 |
|---|---|---|
| train MSE | 0.458 | **0.00597** |
| eval MSE | — | **0.00640** |
| 耗时 | — | 51 秒 |

达标：MSE < 0.01 ✓（step 400 即 0.00916 达标）。

### 重建效果验收（`trainer/eval_ae.py`）
- 整体随机采样（4000 帧）：MSE 0.00342，PSNR 均值 **41.02 dB**（中位数 41.59）
- expert 子集（400 序列）：MSE 0.00802，PSNR 均值 27.14 dB（机械臂动作更多、更难重建）
- 视觉确认：桌面、红色目标圆盘、立方体、机械臂末端均可清晰辨认
- 最优检查点：`outputs/checkpoints/ae_best.pt`（latent=64，step=1000，8.3MB）

### 与 RSSM 的对接
AE 隐空间已统一为 **64 维**（`configs/world_model.yaml` latent_dim: 64），
RSSM 随机态维度同步为 64（拼接特征 264 = det 200 + stoch 64）。
