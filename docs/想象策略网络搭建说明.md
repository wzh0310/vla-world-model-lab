# 想象策略网络搭建说明（隐空间 Actor-Critic）

本阶段实现「世界模型内训练策略 → 零样本迁移真实环境」闭环的核心组件：**适配 RSSM 隐空间的随机 Actor-Critic 策略网络**。基于已训练并冻结的世界模型，策略完全在隐状态空间中决策，为后续想象训练与样本效率对比打基础。

## 一、设计目标

| 目标 | 实现方式 |
|---|---|
| 策略在隐空间决策 | Actor/Critic 输入为 RSSM 拼接特征 `det‖stoch`，不直接接触像素 |
| 探索能力 | Actor 输出高斯分布均值 μ 与对数标准差 log_std，可重参数化采样 |
| 动作对齐环境 | 网络输出归一化到 `[-1,1]`，`ActionScaler` 映射回真实动作范围 |
| 维度严格对齐 | `build_from_world_model(wm)` 自动读取 `wm.feat_dim`，杜绝维度错配 |
| 想象训练可微 | `tanh` 重参数化保证梯度沿「奖励→动作→策略参数」回传 |

## 二、网络结构（轻量 MLP）

**Gaussian Actor**（输入 `feat_dim=248` = det 200 + stoch 48）
```
Linear(248→256) → SiLU → Linear(256→256) → SiLU
  ├→ Linear(256→4) → tanh → μ      ∈ [-1,1]
  └→ Linear(256→4) → clamp(-5,2) → log_std
采样: a = tanh(μ_raw + exp(log_std)·ε),  ε~N(0,I)
```
- 输出层小初始化（uniform ±3e-3），避免早期标准差过大导致近随机游走。
- `sample(deterministic=False)` 随机采样；`True` 取均值 `tanh(μ_raw)` 用于评估。
- `log_prob()` 提供近似高斯对数概率（tanh 前潜变量空间，后续训练可补雅可比修正）。

**Value Critic**（输入同为 248）
```
Linear(248→256) → SiLU → Linear(256→256) → SiLU → Linear(256→1) → V
```

参数量：Actor + Critic 合计 **261,385**。

## 三、接口适配

### 1. 维度对齐
基线世界模型 `stoch=48 / det=200`，隐特征 `feat_dim=248`。策略通过
`build_from_world_model(wm)` 从加载的检查点读取真实维度构建，切换不同 stoch 维度的检查点时无需手工改参数。

### 2. 动作范围映射
数据集动作的归一化口径：
- 真实范围：`low=[-0.02,-0.02,-0.02,0]`，`high=[0.02,0.02,0.02,1]`
- 归一化：`norm = (a-low)/span*2 - 1`
- 反归一化（推理落地）：`a = (norm+1)/2*span + low`

`ActionScaler` 提供 `to_env()` / `from_env()` 双向映射，并从 HDF5 属性自动读取 `action_low/action_high`。

## 四、基础验证结果

验证脚本：`trainer/verify_actor_critic.py`（vla 环境运行）

```
[WM] 已加载 abl2_stoch48/wm_best.pt: stoch=48 det=200 feat=248
[VERIFY] 轨迹=traj_0000 隐维度=248 热身=3帧 想象=10步 设备=cuda
[VERIFY] 梯度链路 OK：8/14 个参数收到非零梯度
[VERIFY] 想象 rollout OK：10 步动作 shape=(10,4) 范围=[-0.950,0.890]
ACTOR_CRITIC_IMAGINATION_OK
```

验证覆盖：
1. 从真实轨迹前 3 帧 observe 建立后验起点（teacher-forcing 仅用于初始化）；
2. 之后 10 步**纯想象**（不接任何真实图像），每步 `feat → actor.sample() → imagine_step()`；
3. 逐动作断言维度 (1,4)、范围 ∈[-1,1]、映射回真实范围后位置 ≤0.02、夹爪 ∈[0,1]；
4. 冻结世界模型后，`reward_head` 经想象链的梯度能回传到策略参数（重参数化可微成立）。

## 五、与旧版 `models/policy.py` 的关系

| 模块 | 定位 | 分布 | Critic | 用途 |
|---|---|---|---|---|
| `models/policy.py` | 最小 Demo | 确定性均值 | 无 | 早期想象策略 Demo（保留兼容） |
| `models/actor_critic.py` | 正式组件 | 高斯随机 | 有 | 本阶段想象策略训练、样本效率对比 |
