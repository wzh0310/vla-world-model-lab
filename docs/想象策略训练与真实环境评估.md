# 想象策略训练与真实环境评估（零样本迁移）

本阶段实现 Dreamer 核心的「想象轨迹训练」闭环，并完成从世界模型到 PushCube 真实环境的零样本迁移验证。核心结论：**策略在世界模型内确实学会了获取奖励（想象回报 -0.04→+0.85），但受 sim-to-real 间隙与任务导航难度限制，真实环境 20 回合成功率为 0%**。这一结果结合专家基线（全监督 ACT 也仅 30%）得到合理解释。

## 一、想象训练循环 `scripts/train_imagine_policy.py`

### 1.1 完整流程（全程不接触真实环境）
1. **采样起点**：从离线轨迹随机采样 B 个起点，用真实首帧逐帧 `observe` 建立 RSSM 后验初始状态（仅初始化，no_grad）；
2. **想象展开 H 步**：冻结世界模型，当前 Actor 逐步 `sample()` 出动作（重参数化）→ `imagine_step()` 推进隐状态 → `reward_head` 预测每步奖励 → Critic 给出价值 V；同时记录 log_prob 与策略熵；
3. **λ-return 优势**：从后向前递推 `R_t = r_t + γ[(1-λ)V(s_{t+1}) + λR_{t+1}]`，末步 bootstrap `R_H = V(s_H)`，优势 `A = R - V`；
4. **三类损失**：
   - 策略损失：Dreamer 标准 `-logp·A` 与 PPO 裁剪项各占 0.5（on-policy 下裁剪退化为约束项）；
   - 价值损失：**Huber**（delta=1.0，抗 bootstrap 传播的异常回报）；
   - 熵正则：`-entropy_coef·entropy`，鼓励探索；
5. **仅更新 Actor + Critic**，世界模型全程 `requires_grad=False`。

### 1.2 训练稳定性调优（关键工程经验）
首轮全量训练（H=15, lr_critic=3e-4, MSE, 熵系数 1e-3）**发散**：value_loss 从 0.25 飙至 36、熵变负（策略坍缩）、想象奖励下降。这是「函数逼近 + 自举 + 策略分布漂移」的致命三要素问题。系统性修复：

| 措施 | 原值 | 修后 | 作用 |
|---|---|---|---|
| 价值损失 | MSE | Huber(δ=1) | 抗异常回报，抑制价值发散 |
| Critic 学习率 | 3e-4 | 1e-4 | 稳定自举更新 |
| 价值损失权重 | 0.5 | 0.3 | 降低价值项主导 |
| 熵正则系数 | 1e-3 | 1e-2~2e-2 | 防止策略坍缩 |
| log_std 下限 | -5 | -2 | 避免 log_prob 中 1/σ² 放大梯度 |
| 想象步长 H | 15 | 10~12 | 减少复合误差 |
| λ | 0.95 | 0.9 | 降低自举方差 |
| 奖励裁剪 | 无 | [-1,1] | 抑制分布外异常奖励 |
| 梯度裁剪 | 1.0 | 0.5 | 稳定更新 |

### 1.3 最优权重选择
用**固定探针起点**（全程复用的同一批初始状态）每 10 epoch 无方差评估想象回报，保存回报最高 epoch 的策略权重作为最终输出（避免末轮抖动）。

### 1.4 训练结果
| 版本 | 配置 | 探针回报 | 想象奖励 | 状态 |
|---|---|---|---|---|
| v1（初始修复） | 200ep, H=10, 熵1e-2 | -0.041 → +0.015 | 0.008→0.093 | 稳定但策略弱 |
| **v2（强化）** | **400ep, H=12, batch128, 熵2e-2** | **-0.04 → +0.85** | **0.07→0.54** | **稳定收敛，采用** |

v2 的价值损失稳定在 0.2~0.4，策略梯度范数平稳，探针回报单调上升——证明策略在世界模型内确实学会了获取奖励。

## 二、零样本迁移评估 `scripts/eval_imagine_policy.py`

在 **mujoco 环境**运行（vla 无 mujoco；两环境隔离保持）。推理链路：
```
观测图像(224) → resize 64 → ConvEncoder → RSSM observe 跟踪后验隐状态
→ Actor 采样动作[-1,1] → ActionScaler 映射回真实动作范围 → env.step
```
世界模型与策略权重均 freeze，不作任何微调；评估口径与项目已有专家基线一致（PushCubeEnv, 50 步上限, 成功=cube 到目标<0.03m）。

### 2.1 结果（v2 策略，20 回合）
| 指标 | 数值 |
|---|---|
| 成功率 | **0%** |
| 平均累计奖励 | -2.485 |
| 平均最终距离 | 0.196 m（范围 0.173~0.225）|
| 平均步数 | 50（跑满）|

### 2.2 失败原因分析（重要）
1. **任务本身困难**：项目已有的全监督专家策略 ACT（4000 步监督训练）在该环境成功率也仅 **30%**（best）/13%（final），随机策略更低。0% 并非异常，而是零样本设定下的能力边界体现。
2. **最终距离 ≈ 初始距离**：立方体起点约 [0.604,-0.127]，目标 [0.82,-0.12]，相距约 0.216m；各回合终点距离 0.17~0.22m，说明立方体几乎没被推动。策略只学到短程（10~12 步）的推箱动作，缺乏「从 HOME 导航到立方体后方再推」的长程行为。
3. **sim-to-real 间隙**：想象训练用数据集真实动作的后验起点，评估用策略自身动作闭环跟踪，隐状态分布存在 off-policy 偏移；奖励头对偏离专家分布的动作预测不准，导致想象中"看起来在进步"但实际动作无法迁移。
4. **奖励信号弱**：世界模型奖励头虽在专家分布内 MAE 低（0.024），但对策略探索出的分布外动作缺乏可信梯度。

### 2.3 按预定调优方向已做的尝试
- 缩短想象步长（15→12）、增大熵系数（1e-3→2e-2）、调整奖励/价值权重（value_coef 0.5→0.3）——想象内指标大幅改善，但 sim2real 迁移仍未成功，印证瓶颈在世界模型保真度与长程导航，而非训练超参。

## 三、运行命令

```bash
# ===== vla 环境：想象策略训练 =====
PY_VLA=/opt/miniconda3/envs/vla/bin/python
cd /data/wzh/robot/vla-world-model-lab
$PY_VLA scripts/train_imagine_policy.py \
  --ckpt outputs/abl2_stoch48/checkpoints/wm_best.pt \
  --data outputs/data/trajectories.h5 \
  --epochs 400 --batch-size 128 --horizon 12 --entropy-coef 2e-2 \
  --out-dir outputs/imagine_policy_v2

# ===== mujoco 环境：真实环境评估 =====
PY_MUJOCO=/opt/miniconda3/envs/mujoco/bin/python
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 $PY_MUJOCO scripts/eval_imagine_policy.py \
  --policy outputs/imagine_policy_v2/imagine_policy.pt --episodes 20 --device cpu
```
