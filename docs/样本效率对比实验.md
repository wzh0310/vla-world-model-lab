# 样本效率对比实验报告

## 实验目的

量化「世界模型 + 想象训练」相对于「纯视觉 PPO」的样本效率差异，产出项目核心结论：
在相同训练数据量（10% / 30% / 50% / 100%）下，两种范式在 PushCube 真实环境中的
性能表现，以及达到同等性能所需的样本节省比例。

## 实验设计

### 两组对照

| 组 | 方法 | 训练数据量映射 | 训练产物 |
|---|---|---|---|
| 对照组 | 纯视觉 PPO（SB3 CnnPolicy + 4 帧堆叠，端到端在线 RL） | 环境交互步数 20万 / 60万 / 100万 / 200万（对应 10/30/50/100%） | 已有 `full_2m` 中间 checkpoint |
| 实验组 | 世界模型（RSSM + 重建/KL/奖励/价值四损失）→ 想象策略（λ-return + PPO + 熵） | 离线轨迹 10 / 30 / 50 / 100 条（对应 10/30/50/100%，嵌套子集） | 各档重训世界模型 + 想象策略 |

### 受控变量

- **唯一变量为数据量**：世界模型各档严格沿用最优配置（stoch48/det200/batch16/kl1.5/freebits0.05/curriculum30），想象策略沿用 v2 超参（400 epoch / batch128 / horizon12 / 熵2e-2）。
- **同一动力学、同一评估器**：两组都在 PushCube-v0 真实环境评估，固定起点（randomize_start=False），seed 0~29，每回合≤50步。
- **各自最优观测口径**：PPO 用训练时的 84×84 灰度 + 4 帧堆叠；世界模型用 demo 224 图 → 64×64 → ConvEncoder → RSSM 后验跟踪 → Actor。这是合理的，因为样本效率对比关心的是「各范式在自身最佳条件下的样本利用率」。

### 为何主曲线用连续指标

PushCube 是一个 50 步、每步 ±2cm 增量的精细操作任务，二元成功率极难。项目已有的
权威 benchmark（100 回合）显示：纯视觉 PPO 满数据成功率为 **0%**，世界模型想象策略
也是 **0%**（本实验独立复现一致）。若以二元成功率为纵轴，两条曲线都平在 0，无法刻画
样本效率差异。因此主曲线采用两个**连续、非饱和**指标：

1. **累计奖励**（cumulative reward，越高越好）
2. **最终到目标距离**（final distance，越低越好）

二元成功率作为辅助记录一并呈现。

## 数据子集

从世界模型全量数据集（100 条轨迹 / 3324 帧）按固定 seed 切分嵌套子集：

| 比例 | 轨迹数 | 帧数 |
|---|---|---|
| 10% | 10 | 333 |
| 30% | 30 | 1017 |
| 50% | 50 | 1699 |
| 100% | 100 | 3324 |

## 结果

| 数据量 | 纯视觉 PPO（成功率/奖励/距离） | 世界模型+想象（成功率/奖励/距离） |
|---|---|---|
| 10% | 0% / -1.4824 / 0.1885 | 0% / -3.6187 / 0.2000 |
| 30% | 0% / -0.5175 / 0.0933 | 0% / -1.5336 / 0.1922 |
| 50% | 0% / -1.4824 / 0.1885 | 0% / -3.5973 / 0.2000 |
| 100% | 0% / -2.4887 / 0.2000 | 0% / -3.5819 / 0.2000 |

## 样本节省比例

**样本节省比例：无法计算（性能饱和在失败水平）。** 两组在全部四档数据量下，真实环境成功率均为 0%，最终距离均集中在 0.19~0.20 m（≈立方体起点到目标距离，说明立方体几乎未被推动）。由于没有任何档位达到非零成功率，任何基于连续指标的『达标』都是失败水平之间的比较，属于假阳性，因此本实验诚实地将样本节省倍数判定为无统计意义（`performance_saturated_at_zero=True`，`sample_saving_factor=None`），而不把失败水平之间的数值差异包装成样本效率优势。

作为参考：`sample_efficiency_summary.json` 仍完整记录了两组各档的成功率、累计奖励、最终距离，供后续在更易解的任务或更高保真世界模型上复现时计算样本节省。

## 关键发现与结论

1. **两组在纯视觉路线下均零样本迁移失败。** 纯视觉 PPO（在线 RL，最多 200 万步）与世界模型想象策略（离线轨迹 + 想象训练）在 PushCube 真实环境成功率全部为 0%，与项目既有权威 benchmark 一致。这印证了该任务（50 步、每步 ±2cm 增量、需先导航到立方体后方再推）对纯视觉方法的难度。

2. **连续指标揭示 PPO 训练后期策略坍缩。** PPO 60 万步时奖励 -0.5175、最终距离 0.0933 m，反而明显优于 200 万步的 -2.4887 / 0.2000 m——更多在线交互并未带来单调改进，收敛后期策略输出饱和动作导致性能退化。世界模型组在同一口径下也呈非单调（30% 数据 -1.5336 / 0.1922 相对最好）。

3. **世界模型的价值体现在想象世界内的学习，而非当前保真度下的零样本迁移。** 前期实验已证明：固定探针起点下想象回报随训练单调上升（-0.04 → +0.85），世界模型能学到有意义的任务奖励结构；但奖励头对分布外动作的保真度不足 + 长程导航能力缺失，导致 sim-to-real 间隙无法在真实环境转化为成功率。这是当前轻量世界模型（stoch48 / 3324 帧离线数据）的能力边界，而非训练或工程缺陷。

4. **提升方向。** 若要让样本效率优势在真实成功率上显现，需要：（a）提高世界模型对分布外状态的奖励/转移保真度（扩充覆盖更多中间状态的数据）；（b）引入分层或长程想象策略解决『先导航到立方体后方』的行为；（c）在更易解的操纵任务上验证，避免二元成功率饱和掩盖方法差异。
